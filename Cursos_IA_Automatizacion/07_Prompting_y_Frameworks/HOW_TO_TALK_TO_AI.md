# HOW TO TALK TO AI — Pipeline Creativo Completo de Tim Koda

## Propósito
Breakdown del workflow completo que Tim Koda usa para crear sus Reels cinematográficos: desde una idea hasta el reel final con multi-ángulos, motion y sound design. 5 pasos: concepto → ángulos → cámara motion → edición → sonido.

## Conceptos Clave
- **Midjourney para exploración** — iterar composiciones, iluminación y atmósfera hasta encontrar el "mundo" correcto
- **Nano Banana Pro para multi-ángulos** — genera múltiples perspectivas del mismo escenario (Inside Freepik o Higgsfield)
- **Kling 2.5 First-to-Last Frame** — transición fluida entre dos estáticas (efecto "Bolt Cam digital" → cámara que vuela de un ángulo al siguiente)
- **DaVinci Resolve** — corte, reordenamiento, timing, pacing intenso y dinámico
- **Sound design como último paso** — impactos, whooshes, ambience → hace que el movimiento se sienta físico
- **Pipeline completo** — 1 idea → multi-angle shoot → motion → edit → final cinematic reel

## Plataformas y APIs
- Midjourney (concepto base)
- Nano Banana Pro en Freepik o Higgsfield (multi-ángulos)
- Kling 2.5 (First-to-Last Frame)
- DaVinci Resolve (edición)
- Sound design libraries
