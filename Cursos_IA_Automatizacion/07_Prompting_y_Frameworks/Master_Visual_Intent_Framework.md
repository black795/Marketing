# Master Visual Intent — El Framework Rápido

## Propósito
Framework de 3 pasos para definir la intención visual completa ANTES de escribir el prompt. Garantiza que todos los elementos visuales soporten el mismo sentimiento. Evita el error de empezar con el prompt antes de saber qué se quiere comunicar.

## Conceptos Clave
- **Visual Intent First** — definir feeling → references → elementos → ENTONCES escribir el prompt
- **3 pasos** — 1. Define el Feeling (emoción + mood) 2. Find References (películas, arte, diseño) 3. Break Down Elements (COLOR, LIGHTING, COMPOSITION, TEXTURE, SCALE, STYLE)
- **Quick test de mood** — "Si fuera música, ¿qué género sería?"
- **References sin copiar** — extraer la esencia, no imitar
- **Brand Formulas** — Apple: minimal+clean whites+soft light; Nike: bold contrast+dramatic light; Chanel: monochrome+soft golden+symmetry
- **6 elementos clave** — Color (dominante + tono), Lighting (tipo + fuente), Composition (layout + ángulo), Texture (material), Scale (épico/íntimo/macro), Style (fotorrealista/estilizado)
