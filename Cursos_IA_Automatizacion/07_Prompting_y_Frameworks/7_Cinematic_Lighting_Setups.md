# 7 Cinematic Lighting Setups — Prompts Completos

## Propósito
7 setups de iluminación cinematográfica con prompts exactos y listos para usar. Cada setup produce una emoción completamente diferente con el mismo sujeto. Incluye: mood, cuándo usar, características visuales y prompt completo con specs de cámara.

## Conceptos Clave
- **Golden Hour** — warm/romantic/aspirational; para fashion, lifestyle, luxury
- **Low Key** — dark/mysterious/intense; para editorial, drama, high-contrast
- **Spotlight** — theatrical/focused/dramatic; para performance, reveals, statements
- **Chiaroscuro** — classical/artistic/Renaissance-inspired; para retratos artísticos, high-end editorial
- **Cutter Lights** — edgy/bold/graphic/modern; para fashion editorial, bold statements
- **Hard Flash Photography** — raw/authentic/paparazzi; para street fashion, party content
- **Silhouette** — mysterious/dramatic/minimalist; para reveals, minimalist aesthetic
- Cada prompt incluye: specs de cámara (marca, lente, apertura), settings y características visuales

## Plataformas y APIs
- Compatible con: Midjourney, Flux, Recraft V4, Gemini
- Sujetos customizables en cada prompt (mantener la descripción de iluminación intacta)
