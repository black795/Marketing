# RECREATOR — Extensión Chrome para Reverse-Engineer de Prompts

## Propósito
Extensión de Chrome que analiza cualquier imagen en internet y extrae/recrea el prompt original que la generó. Permite aprender de imágenes existentes, replicar estilos y recrear referencias visuales en Midjourney, Higgsfield u otros generadores.

## Conceptos Clave
- **Reverse engineering de prompts** — analiza imagen → extrae las instrucciones de prompt detrás de ella
- **Recreación en generadores** — el prompt extraído se puede usar directamente en Midjourney, Flux, Higgsfield
- **Búsqueda de similares** — ayuda a encontrar imágenes con estética similar
- **Aprendizaje de estilos** — entender qué palabras producen qué resultados visuales
- **Integración directa** — instalación como extensión Chrome, funciona en cualquier página web

## Plataformas y APIs
- RECREATOR (extensión Chrome)
- Compatible con: Midjourney, Higgsfield, Flux, DALL-E (destinos para recrear)

## Bloques de Código
Sin bloques de código extraíbles — es una extensión de interfaz gráfica.
