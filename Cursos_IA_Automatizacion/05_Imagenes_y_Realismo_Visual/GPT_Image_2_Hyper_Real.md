# GPT Image 2 — Generación de Frames Hiper-Realistas

## Propósito
Uso de GPT Image 2 (OpenAI) para generar frames hiper-realistas para producción de video y contenido de marca. Especializado en calidad fotográfica de nivel editorial.

## Conceptos Clave
- **GPT Image 2** — modelo de generación de imagen de OpenAI con capacidades hiper-realistas
- **Hyper-real frame generation** — creación de frames individuales que sirven como base para video
- **Emergent.sh integration** — GPT Image 2 se usa dentro del stack de Emergent para landing pages
- **Editorial quality** — calidad suficiente para uso en campañas de marca y publicaciones

## Plataformas y APIs
- OpenAI API (GPT Image 2)
- Emergent.sh (stack integrado: Claude Opus + GPT Image 2 + Next.js)

## Notas
Integrado principalmente dentro de Emergent.sh para la creación de sitios web con imágenes editoriales.
