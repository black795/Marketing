# THE REALISM FORMULA — Piel Ultra-Realista con JSON Prompting

## Propósito
Fórmula de prompting en JSON para generar texturas de piel ultra-detalladas y realistas usando Gemini 2.5 Flash Image. El prompt JSON estructura cada parámetro de iluminación, composición, estilo y restricciones para resultados controlados y reproducibles.

## Conceptos Clave
- **JSON Prompting** — técnica de prompt estructurado que da control total sobre outputs de imagen
- **Gemini 2.5 Flash Image** — modelo de Google para generación de imagen con alta fidelidad
- **Ultra-detail skin** — poros visibles, peach fuzz, micro-imperfecciones, iluminación lateral artificial
- **Macro lens / extreme close-up** — ángulo de cámara que maximiza el detalle de textura
- **Exclusiones clave** — sin maquillaje, sin suavizado de piel, sin fundación → resultado orgánico

## Plataformas y APIs
- Google Gemini 2.5 Flash Image (modelo: `gemini-2.5-flash-image`)
- API de Google AI (para uso programático)

## Bloques de Código
- `Scripts_Automatizacion/realism_formula_skin_prompt.json` — prompt JSON completo para generación de skin ultra-realista (sujeto, entorno, estilo, cámara, restricciones)
