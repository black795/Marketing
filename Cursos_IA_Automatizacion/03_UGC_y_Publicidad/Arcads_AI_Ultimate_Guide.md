# Arcads AI — Ultimate Guide de UGC con Actores IA

## Propósito
Plataforma que genera videos UGC realistas con actores IA que hablan y se mueven como personas reales. Controlable por API para automatización con Claude Code. Ideal para agencias de UGC que necesitan escalar producción de ads.

## Conceptos Clave
- **Arcads AI** — plataforma de generación de videos UGC con actores IA hiperrealistas
- **Control de script** — el creador define el guión exacto; el actor IA lo entrega
- **API access** — Arcads tiene API para integración con Claude Code y automatización
- **Actor consistency** — misma "persona" IA en múltiples videos de campaña
- **UGC formula** — Hook (0-3s) + Value (3-15s) + Proof (15-20s) + CTA (20-25s) = 25 segundos

## Plataformas y APIs
- Arcads AI (API key requerida para automatización)
- Claude Code (para el agente UGC Agency)

## Bloques de Código
