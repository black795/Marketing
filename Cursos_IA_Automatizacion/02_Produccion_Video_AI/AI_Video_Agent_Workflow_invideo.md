# AI Video Agent Workflow — Multi-Asset Brand Campaign con invideo Agent One

## Propósito
Primer agente de video IA que produce campañas multi-asset completas de marca con consistencia entre todos los assets. Elimina el pipeline manual de arrastrar referencias a Sora, cambiar a Veo, manejar Kling — el agente selecciona el modelo correcto para cada plano.

## Conceptos Clave
- **invideo Agent One** — agente que genera campañas completas de video de marca (múltiples assets, múltiples formatos)
- **Model Routing automático** — el agente elige Sora, Veo, Kling o Seedance según las necesidades de cada plano
- **Multi-asset consistency** — todos los videos de la campaña mantienen el mismo look, marca y personajes
- **Brand Campaign System** — brief de marca → stories de producto → reels → ads → contenido orgánico

## Plataformas y APIs
- invideo Agent One (plataforma principal)
- Sora 2 (OpenAI video model)
- VEO 3.1 (Google video model)
- Kling (Kuaishou video model)
- Seedance 2.0 (ByteDance video model)

## Bloques de Código
Sin bloques de código extraíbles — flujo controlado por el agente invideo.
