# Cinematic Aesthetic Workflow — Recrear Estéticas de Películas con TapNow

## Propósito
Proceso de 3 pasos para crear secuencias cinematográficas que replican con exactitud la estética visual de películas famosas: colores, iluminación, movimiento de cámara y calidad de producción.

## Conceptos Clave
- **TapNow AI** — plataforma que genera secuencias con movimiento de cámara y color grading precisos según la película de referencia
- **Estéticas populares** — Barbie (pasteles rosa), Blade Runner (cyberpunk neón), Wes Anderson (pasteles simétricos), Oppenheimer (drama de época), Marvel (épico blockbuster)
- **3 pasos** — Drop Film Inspiration → Prompt Scene → Generate in TapNow
- **Workflow accesible en** — `app.tapnow.ai/#/tapflow/view/53cb8f51`
- **Tips** — ser específico sobre la película, no mezclar estilos, estudiar la cinematografía real

## Plataformas y APIs
- TapNow AI (100 créditos gratis con código de Tim Koda)

## Bloques de Código
- `Scripts_Automatizacion/cinematic_aesthetic_scene_prompt.txt` — estructura de prompt para replicar estética cinematográfica de película en TapNow
