# The Emotional Branding System — Identidad de Marca que se Siente Humana

## Propósito
Sistema de 3 prompts para construir una identidad de marca completa que se siente hecha a mano, no computada por IA. Combina estructura emocional, dirección visual y generación de assets con keywords de textura orgánica.

## Conceptos Clave
- **3-step system** — 1. Lock Brand Structure (DNA emocional) → 2. Translate to Visual Direction → 3. Generate Brand Assets
- **Brand Structure Prompt** — define: emoción en 3 segundos, "el enemigo" de la marca, personalidad (cómo habla/viste/se mueve)
- **Visual Direction Prompt** — traduce la emoción a: tipografía, paleta (con hex codes), texturas, estilo de personaje/mascota, dirección fotográfica, principios de layout
- **Asset Generation Prompt** — genera 5 assets: logo, mascota, packaging, sticker sheet, Instagram template
- **Texture Keywords Library** — chalk texture, ink bleed, paper grain, watercolor edges, kraft paper, screen print halftone, rough edges, hand-drawn feel
- **Por qué las marcas IA se ven iguales** — todos saltan al prompt sin definir la emoción primero

## Plataformas y APIs
- LLMs (Claude, ChatGPT, Gemini) para los 3 prompts
- Midjourney / Flux / Recraft (ejecución de los 5 assets)

## Bloques de Código

- `Scripts_Automatizacion/emotional_branding_asset_generation_prompt.txt` — Prompt 3: genera los 5 assets con keywords de textura orgánica
- `Scripts_Automatizacion/emotional_branding_texture_keywords.txt` — biblioteca de keywords para assets que parecen hechos a mano
