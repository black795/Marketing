# The Emergent Stack — Sitios Web con IA (Claude Opus + GPT Image 2 + Next.js)

## Propósito
Stack completo para crear sitios web de marca profesionales usando Emergent.sh: Claude Opus como arquitecto, GPT Image 2 para imágenes editoriales y Next.js como framework, con hosting incluido. Template de brief para dar al agente toda la información necesaria.

## Conceptos Clave
- **Emergent.sh** — web builder IA que combina Claude Opus + GPT Image 2 + Next.js con hosting
- **Brand Site Brief** — template estructurado que incluye: Brand, Audience (quiénes son + qué quieren + qué temen), Positioning, Key sections, Brand voice references, Mood (una palabra), NOT (3 cosas que la marca nunca debe sentir)
- **Claude Opus como arquitecto** — genera la estructura, contenido y código del sitio
- **GPT Image 2** — genera imágenes editoriales hiperrealistas para el sitio
- **Next.js** — framework de React para producción; Emergent lo hostea automáticamente
- **Deliverable** — sitio Next.js completo listo para deploy en hosting de Emergent

## Plataformas y APIs
- Emergent.sh (web builder + hosting)
- Anthropic Claude Opus (motor de IA del builder)
- OpenAI GPT Image 2 (generación de imágenes)
- Next.js (framework)

## Bloques de Código
- `Scripts_Automatizacion/emergent_stack_site_brief_template.txt` — template de brief de marca para darle a Emergent.sh con todas las secciones requeridas
