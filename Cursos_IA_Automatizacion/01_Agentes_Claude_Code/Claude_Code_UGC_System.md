# Claude Code UGC System

## Propósito
Guía de instalación de Claude Code en Windows para configurar un sistema de producción de contenido UGC automatizado. Un solo comando PowerShell instala todo el entorno.

## Conceptos Clave
- **Claude Code en Windows** — instalación vía script PowerShell oficial de Anthropic
- **UGC (User-Generated Content)** — contenido estilo usuario real generado con IA
- Integración con herramientas de video como Kling, Higgsfield y Arcads

## Plataformas y APIs
- Windows PowerShell
- Anthropic CLI (`claude.ai/install.ps1`)
- Claude Code (plan Pro o superior)

## Bloques de Código
- `Scripts_Automatizacion/install_claude_code_windows.ps1` — instalación de Claude Code en Windows con un solo comando
