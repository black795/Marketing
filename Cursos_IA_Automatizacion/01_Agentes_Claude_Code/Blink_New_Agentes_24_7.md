# Blink.new — Deploy de Agentes Claude Code 24/7

## Propósito
Plataforma para desplegar agentes Claude Code que corran continuamente en la nube sin necesitar tu computadora local encendida. Permite automatizar flujos creativos (generación de contenido, publicación, monitoreo) de forma autónoma.

## Conceptos Clave
- **Blink.new** — plataforma cloud para hospedar y ejecutar agentes Claude Code de forma permanente
- **Deploy 24/7** — agentes que corren sin intervención humana continua
- **Automatización autónoma** — flujos creativos que se ejecutan solos (generación, publicación, análisis)
- Complementa el stack local de Claude Code con capacidad de ejecución continua en la nube

## Plataformas y APIs
- Blink.new (plataforma de hosting de agentes)
- Claude Code (Anthropic API)
- APIs de destino: cualquier API que el agente deba controlar

## Notas
No hay bloques de código extraíbles — el flujo de deploy es visual dentro de la plataforma Blink.new.
