# Character DNA System — Framework de Consistencia de Personajes

## Propósito
Framework sistemático para definir y mantener personajes IA 100% consistentes a través de múltiples generaciones. El "DNA" del personaje se documenta en una plantilla estructurada que cubre físico, personalidad, voz y estilo, generando un párrafo de prompt master.

## Conceptos Clave
- **Character DNA** — descripción completa y sistematizada de un personaje que garantiza consistencia
- **5 secciones** — PHYSICAL, PERSONALITY, VOICE, STYLE, y PROMPT (párrafo combinado)
- **Prompt master** — un párrafo que combina todos los atributos del personaje para uso en cualquier generador
- **Consistencia cross-platform** — el mismo DNA funciona en Midjourney, Flux, Seedance, Kling, etc.
- **JSON Prompting** — técnica de prompting estructurado para control total de salidas

## Plataformas y APIs
- Compatible con todos los modelos de generación de imagen y video (Midjourney, Flux, Nano Banana, Seedance, Kling)

## Bloques de Código
- `Scripts_Automatizacion/character_dna_template.txt` — plantilla completa de Character DNA con todas las secciones
