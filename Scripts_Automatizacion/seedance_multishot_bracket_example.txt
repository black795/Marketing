# Propósito: Ejemplo completo de generación multi-plano con bracket syntax de Seedance 2.0
# Origen: Seedance 2.0 Master Guide
# API Keys necesarias: Ninguna (acceso vía OpenArt)
# Cómo usar: Adaptar los brackets con tu personaje y escena; mantener STYLE y CONSTRAINTS fuera de los brackets

=== REGLAS DEL BRACKET SYNTAX ===
- Cada bracket = UN plano con UN movimiento de cámara
- Referenciar el mismo personaje entre planos: "the same male traceur", "Same dancer"
- Duración total: 6-15 segundos en todos los planos
- Máximo 5 planos por generación (3 es el sweet spot)
- SIEMPRE terminar con STYLE y CONSTRAINTS GLOBALES FUERA de los brackets
- Nunca mezclar movimientos de cámara dentro de un mismo bracket
